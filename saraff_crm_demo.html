Step 14 of 27 · Data
Export & Backup
All data lives in your browser's localStorage. Export regularly to a shared drive as insurance.
1
Go to ⚙️ Settings → Data Management.
2
Click Export Data — a JSON file downloads containing all customers, invoices, campaigns, business cards and salespeople.
3
Store in a shared drive or cloud folder. Aim to export at least once per week.
4
To restore: Settings → Import Data, select your JSON file.
⚠ Warning: Clearing browser data (cookies/cache) deletes all CRM data. Always export first. Avoid Private/Incognito mode — localStorage is wiped when the window closes.

Step 16 of 27 · Admin: Users & Access
RBAC — What Is It?
Role-Based Access Control. Every User account has a permission matrix: 10 modules × 4 levels. Admins always have full access.
🔐
Why RBAC?
Different team members need different access. A junior sales consultant doesn't need to see Settings or delete invoices. RBAC lets you control this precisely.
📊
10 Modules Covered
Dashboard, Customers, Pipeline, Inventory, Salespeople, Reports, Campaigns, Business Cards, Invoices, Settings — each controllable independently.
🎯
4 Levels Per Module
None (hidden), View (read-only), Edit (add/edit), Full (add/edit/delete + admin actions). Mix and match per module per user.
⚡
Instant Enforcement
Changes take effect on next navigation — no logout required. Sidebar items hide immediately; function-level checks prevent direct URL access too.
